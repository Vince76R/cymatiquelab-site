# CymatiqueLab — mini-site de départ

Cette maquette statique présente une première direction pour le site web CymatiqueLab.

## Comment l'ouvrir

1. Dézipper le dossier.
2. Ouvrir `index.html` dans un navigateur.
3. Modifier les textes dans les fichiers `.html` au besoin.

## Structure

- `index.html` : page d'accueil.
- `pages/experiences.html` : bains sonores et séances.
- `pages/laboratoire.html` : CymatiqueLab Audio Analyzer et tests de fréquences.
- `pages/tests-batons.html` : fiches de bâtons reliées à Sona Materia.
- `pages/audio-binaural.html` : captation 3Dio FS Pro II.
- `pages/a-propos.html` : histoire et storytelling.
- `pages/reserver.html` : Calendly et paiements.
- `pages/ecosysteme.html` : lien entre CymatiqueLab, Sona Materia et Sona Vita.
- `pages/carnet.html` : blog, vidéos et coulisses.
- `assets/logos/` : logos SVG.
- `assets/style.css` : design global.
- `assets/script.js` : menu mobile et détails visuels.
- `docs/` : documents de stratégie.
